Rowglass records source changes independently of the replication engine. When a replica disagrees, it connects the row to its committed history and exports a small, transaction-preserving SQL workload. The included case runs through actual Postgres, PeerDB and ClickHouse.

The journal uses bounded CRC-framed entries, a consistent baseline seal, an exclusive writer lock and explicit durability before feedback. It tolerates a partial trailing frame, rejects complete corruption, and checks source identity and retained WAL before resuming.

A real capture test exposed automatic keepalive feedback advancing beyond the recorder's durability boundary. The transport now controls libpq COPY BOTH feedback explicitly. Its dependency on pinned driver internals is documented, and a regression test verifies the server slot never advances beyond durable evidence on unrelated WAL.

Three contracts that matter

01

A mismatch can be lag

Live snapshots stay labeled live. Controlled lab cuts require source write locks, recorded commit coverage and PeerDB normalization evidence. A timestamp alone does not establish a shared snapshot.

02

Exact values, explicit unknowns

Decimals and JSON numbers retain exact semantics. Null, missing rows, unchanged TOAST and unknown values stay distinct. Visible conflicting target version ties fail the observation.

03

Transactions stay whole

Backward key dependencies retain predecessor rows, key changes and companion writes across tables. Replay produces scratch-schema SQL, not original statements or a proof of minimum size.

Where it fits, and where it does not

For a one-time comparison without captured history, a table-diff tool is simpler. Rowglass is for a bounded investigation where committed source evidence and a runnable handoff matter. It needs a recording before the incident. Full state lives in memory, one sync is performed per commit, and replay is limited to a 256 MiB journal.

Regular tables with stable primary keys and a fixed unfiltered publication are the supported contract. General DDL, failover continuity, arbitrary custom types, sharded destination snapshots and automatic redaction are not supported. Replay omits triggers, foreign keys and original statement predicates. It spans the complete supplied recording, which may extend beyond an earlier observation.
